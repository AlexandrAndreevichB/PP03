| Режим | Performance | Accessibility | Best Practices | SEO |

| Desktop | 87 | 92 | 96 | 90 |
| Mobile | 71	 | 89 | 96 | 88 |

Три главных замечания Lighthouse:
1. Неоптимизированные изображения.
Некоторые изображения каталога имели размер больше необходимого и могли быть дополнительно сжаты. Для улучшения результата рекомендуется использовать форматы WebP или AVIF и задавать размеры изображений заранее.

2. Ресурсы, блокирующие первоначальную отрисовку.
Часть CSS-файлов и JavaScript загружалась до отображения основного содержимого страницы. Для оптимизации можно использовать отложенную загрузку скриптов с помощью defer и вынести второстепенные ресурсы из критического пути загрузки.

3. Неиспользуемый JavaScript и CSS.
В загружаемых файлах присутствовал код, который не требовался для первоначального отображения каталога. Рекомендуется удалить неиспользуемые стили и разделить JavaScript-код на загружаемые по необходимости модули.

Целевые браузеры проекта: Google Chrome, Mozilla Firefox, Microsoft Edge и Safari. Этот набор позволяет проверить работу клиента в браузерах на базе движков Blink, Gecko и WebKit. 
Браузер для отладки и ревью: Google Chrome 131.0.6778.85. 
Почему: Chrome выбран благодаря развитым возможностям Chrome DevTools, наличию встроенного Lighthouse, поддержке эмуляции мобильных устройств, анализу сетевых запросов, отладке JavaScript, просмотру cookie и экспорту HAR-файлов. После отладки в Chrome необходимо выполнить контрольную проверку в Firefox и Safari, поскольку движки Gecko и WebKit могут по-разному обрабатывать CSS, JavaScript и браузерные API.
