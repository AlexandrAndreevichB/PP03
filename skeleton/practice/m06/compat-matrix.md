- Целевые браузеры проекта: Microsoft Edge (Blink / V8), Opera GX (Blink / V8), Mozilla Firefox (Gecko / SpiderMonkey). Проект должен корректно работать на движках Blink и Gecko, чтобы обеспечить совместимость с браузерами, используемыми аудиторией колледжа.
- Браузер для отладки и ревью: Opera GX.
- Почему: Opera GX набрал наибольшую итоговую оценку (4,50 из 5), показал лучшие результаты JetStream (310,5) и MotionMark (1629,23), поддерживает все необходимые инструменты DevTools и успешно прошёл проверку всех функций проекта. Дополнительно Microsoft Edge и Firefox используются для проверки кроссбраузерной совместимости.
