# Модуль 13. Проверка на стороне клиента, итоговый отчёт и дифференцированный зачёт

**18 ч · 04.12–07.12.2026 · ПК 3.1, ПК 3.3, ПК 3.4**

Возьмите реестр полей М02, две целевые среды из М06, серверный контракт М11 и регламент М12. Проверьте выбранную форму на клиенте и настройте локальную проверку индексируемого кода перед коммитом.

1. **04.12 · 9 ч. Валидация и локальный хук.** От main создайте practice/m13. Выберите форму и правило, которое применяется на сервере. В «Библиотеке КАИТ» для формы регистрации (templates/register.php) можно взять обязательность имени или минимальную длину пароля. Проследите вызов из public/index.php до src/Validator.php. Настройте подходящие атрибуты HTML или проверку JavaScript. Для формы проверьте пустое обязательное поле, ошибочное, граничное и корректное значения минимум в двух браузерах. Укажите ожидаемые результаты для каждого случая, включая уход запроса или состояние кнопки/поля.
2. Проверьте локальный pre-commit на отдельной учебной ветке или в пробном клоне. Из Git Bash посмотрите git config --get core.hooksPath. Если уже используются другие хуки, используйте пробный клон или добавьте новую проверку по действующему порядку проекта. Для пробного клона выполните команды ниже. В своих проектах адаптируйте проверку синтаксиса под язык.

~~~bash
chmod +x practice/m13/hooks/pre-commit
git config --local core.hooksPath practice/m13/hooks
git add --chmod=+x practice/m13/hooks/pre-commit
~~~

3. Проверьте обычный коммит и отклонение коммита с учебной ошибкой в индексированном PHP-файле. Исправьте пример, повторите проверку и сохраните результаты в hook-check.md. Укажите, что CI М11 проверяет синтаксис отдельно от локального хука и дополнительно прогоняет тест.
4. **07.12 · 9 ч. Итог.** Сведите результаты М01–М13 в final-index.md: результат, доказательство, ссылка на PR для каждого модуля. В итоговом отчёте покажите цепочку алгоритм → ревью → исправление → проверки. Сверьте индивидуальное задание и дневник из [бланка документов практики](../docs/Документы%20пп.docx) и передайте оформленные документы руководителю. Подготовьте демонстрацию и защитите практику на дифференцированном зачёте.
