## Шаг 1. Кандидаты (1 ч)
Не менее трёх, минимум один настольный открытый: LibreOffice, ONLYOFFICE Desktop Editors, МойОфис (домашняя версия),
онлайн (Яндекс Документы, Р7-Офис облако) или MS Office, если есть. Версии, лицензии, реестр российского ПО (reestr.digital.gov.ru).

## Шаг 2. Критерии, веса, шкала (2 ч)
Предложенные 8 критериев в `comparison.md`; веса можно менять с обоснованием, сумма = 1,00. Шкала 1–5 по результатам тестов.

## Шаг 3. Тесты (9 ч)
| Тест | Что делать |
|---|---|
| Т1 | открыть свой отчёт `…_M03.docx`, проверить титул, оглавление (обновить), списки, колонтитулы; скриншоты |
| Т2 | сохранить отчёт в пакете А, открыть в пакете Б — что изменилось |
| Т3 | выгрузка должников из проекта (`Должники → Выгрузить`) → `debtors.csv` → открыть в табличном редакторе |
| Т4 | `weighted-score.xlsx`: считаются ли формулы, проверка весов, подсветка |
| Т5 | экспорт отчёта в PDF; проверить встроенные шрифты и закладки |
| Т6 | холодный запуск, открытие отчёта, память — 3 замера, лист «Замеры» |
| Т7 | совместная работа: одновременное редактирование, комментарии, правки |
