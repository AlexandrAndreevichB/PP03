## 6. Запуск

```
cp .env.example .env
docker compose up -d
docker compose exec app composer install
docker compose exec app php artisan key:generate
docker compose exec app php artisan migrate --seed
cd frontend && npm install && npm run dev
```

Проблемы: README указывал MySQL, а `docker-compose.yml` поднимает PostgreSQL — в `.env.example` пришлось сменить `DB_CONNECTION=pgsql`. Дописал в README (коммит `docs: исправлена инструкция запуска`).

## 7. Вывод о проекте

Проект небольшой (≈4,5 тыс. строк) со стандартной структурой Laravel и отдельным клиентом на Vue. Знание проекта у одного автора, процесс разработки неформальный: PR забросили, тег всего один. Самая рискованная часть — расчёт свободных окон: `SlotController` чаще всего менялся, многократно исправлялся, и в нём есть признанный автором «костыль». С него стоит начинать ревью. Документация расходится с конфигурацией (MySQL/PostgreSQL) — README доверять нельзя без проверки.
