## 6. Запуск

Шаги запуска проекта:
1. Установить XAMPP на компьютер.
2. Скопировать папку проекта Kait Library в каталог C:\xampp\htdocs\.
3. Открыть панель управления XAMPP.
4. Нажать Start напротив Apache.
5. Нажать Start напротив MySQL.
6. Открыть phpMyAdmin по адресу:
http://localhost/phpmyadmin/


7. Создать базу данных проекта и импортировать SQL-файл, если он имеется.
8. Проверить настройки подключения к базе данных в PHP-файлах проекта.
9. Открыть браузер и перейти по адресу:
http://localhost/Kait-Library/public/


Команды для проверки окружения:
php -v

git --version

git status


Проблемы при запуске и способы решения:
Проблема	Решение
Apache не запускается	Проверить, не занят ли порт 80 другой программой
MySQL не запускается	Проверить состояние службы и порт 3306
Ошибка подключения к базе данных	Проверить название БД, логин и пароль в настройках PHP
Страница не открывается	Проверить расположение проекта в htdocs и адрес localhost
Не отображаются данные книг	Проверить наличие таблиц и записей в MySQL

## 7. Вывод о проекте

В ходе анализа проекта Kait Library было рассмотрено его назначение, предполагаемая структура, используемые технологии и основные пользовательские сценарии. Проект представляет собой веб-приложение библиотечной тематики, предназначенное для работы с информацией о книгах и выполнения основных операций с ними.

На данном этапе проект можно предварительно оценить как учебный или небольшой веб-проект. Для точной оценки его зрелости необходимо проверить исходный код, историю изменений, документацию, обработку ошибок и наличие автоматизированных тестов.

Что бросилось в глаза:
- для работы приложения предполагается использование PHP, Apache и MySQL;
- важную роль играет корректная настройка подключения к базе данных;
- необходимо проверить, насколько подробно описан процесс установки и запуска проекта;
- следует обратить внимание на наличие проверок пользовательского ввода;
- важно проверить, защищены ли операции с книгами и бронированием от некорректных данных и несанкционированного доступа.

Вероятные проблемные места:
1. Недостаточная проверка данных, вводимых пользователем.
2. Возможные ошибки при подключении к базе данных.
3. Недостаточная обработка ошибок при поиске и бронировании книг.
4. Недостаточная документация по установке и настройке приложения.
5. Возможные проблемы с безопасностью при работе с пользовательскими данными.
