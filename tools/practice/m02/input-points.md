# Реестр точек ввода данных

Этот файл используется в модулях 10, 11 и 13. Заполните его честно: «нигде» — тоже ответ.

№	Точка ввода (форма / endpoint / файл)| Поля | Проверка на клиенте | Проверка на сервере	Риск
1	Форма поиска книг (index.php)	Название книги	Да	Не подтверждено	Пустые или некорректные данные
2	Форма бронирования книги	ID книги, данные пользователя	Да	Не подтверждено	Подмена ID, некорректное бронирование
3	Форма авторизации	Логин, пароль	Да	Не подтверждено	Подбор пароля, обход авторизации
4	Форма регистрации	Имя, логин, пароль	Да	Не подтверждено	XSS, регистрация некорректных данных
5	Форма добавления книги (администратор)	Название, автор, описание	Да	Не подтверждено	XSS, SQL-инъекция

Итого точек: 5 (предварительно).

Без подтверждённой серверной проверки: 5.
